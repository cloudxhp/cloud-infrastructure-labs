# Git Basics

## What is Git?
Git is a distributed version control system used to track changes in code.

## Commands Learned

### Initialize Repository
git init

### Check Status
git status

### Add Files
git add .

### Commit Changes
git commit -m "Initial commit"

### Connect to GitHub
git remote add origin <repo-url>

### Push Code
git push -u origin main

## Key Concepts
- Repository
- Commit
- Branch
- Remote
- Push / Pull
